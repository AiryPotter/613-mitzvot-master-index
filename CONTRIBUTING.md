# Contributing

Corrections are welcome. To propose one:

1. **Open an issue** using the "Correction" template, or **open a pull request** that edits the data directly.
2. **Cite a primary source** for every change: the *Sefer HaMitzvot* number, the Torah verse, or the Mishneh Torah chapter.
3. **One fix per pull request.** Keep each change small so it can be checked on its own.
4. **Never paste copyrighted or CC-BY-NC translations.** Write titles and notes in your own words, or quote public-domain texts only.

When editing `data/mitzvot_master_index.csv`, keep it UTF-8 and do not change its line endings.
